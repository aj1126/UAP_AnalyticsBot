# Suggested Commands

## Everyday Development & Execution
- **Run CLI**: `npm start` or `node src/index.js`
- **Launch GUI Dashboard**: `npm run gui` or `node src/gui/server.js`
- **Run Diagnostics**: `npm run diagnose` or `node scripts/diagnostics.js`
- **Run Test Suite**: `npm test` (`node --test --experimental-test-coverage`)
- **Run E2E Simulation**: `npm run verify` (`node verify.js`)
- **Documentation Checks**: `npm run docs:check`

## Windows PowerShell Native Commands
- **Run Specific Test**: `node --test test/telemetry.test.js`
- **Check Project Parity**: `node B:\Repos\antigravity-hud\bin\hud.js sync-projects`
